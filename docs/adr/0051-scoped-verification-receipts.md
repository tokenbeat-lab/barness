# 按功能分阶段验证并只读判定发布回执

测试流程把每次普通修复与固定全库差分、容量负载及整版资格绑定，增加了成本，也让父子入口隐式启动昂贵验证。用户批准测试流程重置，并仅授权首先实施入口迁移与普通验证。

## 决定

pi 只作架构与设计参考；barness 公共行为由自身契约、公共 Client/CLI E2E 和自身真实证据验证。删除冻结 oracle、Node 执行路径、活动差分账本和固定全库发布选择器，保留历史研究、决定及证据。自身目录/价格快照继续由公共 E2E 核对。

日常变更先建立失败场景，再完成受影响普通 E2E。大功能依次完成普通 E2E、受影响自身 live 或有依据的不适用、人工选择 race、人工选择压力或有依据的不适用。失败停止；实施批准和阶段完成不自动授权下一阶段。普通消费者只读留存负载夹具，真实设计负载及其消费者另有显式压力入口。

每次命令生成不可覆盖 attempt，保留真实退出、时间、执行来源/选定输入、工具身份、日志和原生 manifest/audit 精确路径及哈希。源码、测试、依赖或选定输入改变使相应证据失效；仅文档变化须证明完整相关集合相等，并同时记录受测 SHA 与当前提交。

发布命令只消费功能唯一当前状态的不可变投影，核验提交/来源、E2E、受影响 live、race、压力五项事实，不启动验证或发放授权。缺失、失败、NOT_RUN、过期与无依据的不适用均不通过。原生逐文件完整性、脱敏、完整用例、资源释放、真实支持资格、一次性授权与预算继续由原消费者严格判定。离线重放不产生真实资格。

清理工具独立于验证调度，执行前需按已审清理计划核对引用、独占锁、原子批次日志与完整清单；先隔离、观察满七天并复核后才可永久删除。失败、未知、当前/失败依赖与授权账本保留。本次仅实现工具并在临时合成仓库验证，真实清理未开始。

## 取代范围

本决定取代 ADR-0004 中冻结 pi 作为当前行为规格与差分门禁的部分、ADR-0017 中自动收集及固定全库发布判定部分，以及 ADR-0048 中 check/race 两阶段调度入口。上述 ADR 原文和历史结果保留；其协议事实、安全边界及未被本决定取代的资源/原生证据规则继续有效。ADR-0050 的授权与续期边界不变。

## 代价与回滚

调用方必须明确影响范围、必需用例和各阶段授权，维护唯一当前状态及原件指针。收益是普通修改可定向验证，昂贵阶段不会由父子入口隐式启动，发布结论可回溯到实际命令。缺少真实 race/压力/live 时可以交付实现和普通结果，但不能宣称完整发布通过。

实现与普通验收先提交，规范切换另行提交；具体 SHA、原件、偏差和来源相等性见[执行日志](../../.scratch/barness-ai-test-process-review/execution-log.md)与[唯一当前状态](../../.scratch/barness-ai-test-process-review/status.md)。回滚同时回退实现与规范，不恢复已消费授权，也不改写或删除新旧失败记录。

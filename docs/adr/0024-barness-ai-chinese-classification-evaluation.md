# 中文分类业务效果由宿主形成独立证据

工单 16 采用 `ai/examples/chineseeval` 的固定合成中文任务和公共 `Client.Classify`，
使标签定义、真值、指标及保留正文的证据归宿主所有。库继续只负责类型化协议、授权、
用量及调用生命周期；不加入分类阈值、业务路由、转人工或微调。这样标签变化只改变
版本化数据集和评估配置，不扩张协议库，也不会把小样本效果传播为支持矩阵或发布能力声明。

首批任务为四类明确的支持请求、每类六条，共 24 条合成样本。数据来源、任务范围、
标注依据、分布及内容哈希在数据集和报告中完整记录；采用合成数据避免未经批准保存
真实用户正文。这不是生产总体真值，多目标或不确定输入不在任务范围；扩大范围时需
新的标注规则、样本及版本，不能从本次演示推断任意中文业务表现。

宿主分别固定数据集/配置字节哈希、目录/价格版本及哈希、请求和实际响应型号
jev-1.13.0；绑定零重试，独立启用开关与凭据，串行且有有限调用、问题、尝试及时间预算。
取消停止后续发送，已发送请求的明确用量按尝试保留；未上报和部分用量不视为免费或完整。
评估证据只保存合成正文和独立转换的答案视图；Observer 仍只有既有元数据并使用现有审计。

准确率分母包含全部标注样本。成功样本的条件准确率另列；失败与未执行按状态在混淆表
和错误样本索引中保留。未运行是 NOT_RUN，分数为 null；COMPLETE 只表示固定任务全部
完成并通过完整性/审计，没有预设业务准确率门槛。fixture 的完成仍是流程证据，真实结果
必须来自独立 live 评估；任何结果都不写支持矩阵。

厂商 confidence 与所选类别概率分别给出十个等宽可靠性区间和 ECE；多类 Brier 用全部
类别概率计算。confidence 的语义独立于类别概率，将其与正确性对照只是描述性诊断，
不是厂商承诺或已校准概率。统计明确使用可评分样本数量；空区间不插值。24 个明确目标
样本且几乎全在高置信区间，不能证明低置信区域或生产分布已校准。重放固定任务和流程，
保留每次时间和实际答案；不要求真实输出逐次相同。

# MiniMax 国际站目标与历史消费边界

用户明确将尚未正式激活的MiniMax目标从中国区改为国际站。国际站有独立账户与美元定价，服务条款列Nanonoble Pte Ltd.为运营方；这不是请求物理驻留位置保证。官方三套协议schema去除说明元数据后与原中国区结构一致，但该比较不证明账户可用、真实wire续接或正式支持。

当前唯一运行时身份改为ProviderMiniMax/minimax，使用api.minimax.io/v1与api.minimax.io/anthropic；删除未激活的CN路径，不加别名、地区推断或失败fallback。Host明确账户及standard/M Plan用途；M3.1资格和费用不可由M3推断。三份当前国际站自身候选与正式报告、全部旧门禁仍必交。

本决策替代ADR-0037的CN身份、ADR-0039/0040的地区来源依据和ADR-0041的人民币/汇率部分；保留它们的协议能力、可信原生历史、正缓存写缺价保护、精确来源与目录晋升边界。活动M3价格直接采用2026-10-18国际站定价总览的USD/M：低阶0.30/1.20/0.06，高阶0.60/2.40/0.12；不使用被划去旧价或指南旧价例。官方只写512k，512000为本项目保守估算策略，待可靠整数定义再修订，不做高容量收费探测。

原CN失败捕获、源码、intent、收据hashchain及历史分支原样保留。共同candidate规范账本仍计入原2 calls/2 attempts，阶段120/144不变；route/model/purpose有限预算槽仍20/24，Chat槽已消费2/2。精确Provider/endpoint证明身份与预算槽分别校验，历史收据读取只为不可变消费数据，不成为运行时CN兼容层。原CNnative前驱、actual证明和价格不能晋升国际站；新启动名与地区账户别名明确且独占，汇总不能漏计或重复计数，未知消费继续fail-closed。

冻结pi版本、包、完整模型数据与源码pins不变；包装器改用包内已有MINIMAX_MODELS，M3 Messages进入适用差分，Chat/Responses与M3.1分别登记扩展。只替换三条未激活支持占位，保留原十三路线/十四自身身份和四效果合同，总计仍十六路线/十七自身身份。

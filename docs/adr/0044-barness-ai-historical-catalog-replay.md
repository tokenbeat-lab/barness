# 历史目录回放与当前验收分开归属

MiniMax 激活会改变完整内置目录，付费前的完整离线 live 检查却必须先回放旧 GLM 正式采集。回放依据受版本控制的原采集索引，限定原始提交并有界读取该提交的 `ai/release/catalog-snapshot.json`，重算目录哈希并与原报告的版本、哈希及提交逐项核对；Result/Observer 的目录身份仍逐字比较。缺失历史、错误快照和超限读取均拒绝。此路径只生成明确的历史 replay 证据，不发布支持报告；真实 formal、导入和发布仍严格要求当前内置目录及当前执行来源，旧采集不能借此认证当前能力。

MiniMax 候选三模型目录与激活后的完整目录可具有相同版本标签，但哈希不同。回放只在这两个既定目录中按完整版本及哈希选择，禁止仅凭标签推断正式目录；原始捕获、封印与回放来源验证保留。新增 Provider 的历史内容比较只剔除随后独立加入的 Provider 子集，旧模型仍要求完整相等。当前全局目录 pin 在发布快照、四份当前配置/用量 fixture 中同步更新，仅改变目录版本和哈希；历史证据永不重写。预付费检查不缩小 selector，也不允许跳过完整无钥匙检查。

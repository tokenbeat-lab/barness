# 型号集合由审核目录定义，执行能力由代码限定

用户明确要求同类新增仅修改 JSON。按具体型号名称限定目录接纳，使相同协议能力
重复依赖 SDK 发布；决定删除 Kimi、xAI chat/image、TypeSafe image/Box 的名称准入。
该决定替代 ADR-0052、0054、0056 及 Jev 初期实施范围中“只接受指定型号名称”的部分，
不改变各协议、模态、容量、推理、历史、服务端点或计价能力边界。

模型目录提供完整四维身份与已审核能力。代码仍拒绝空 ID、重复身份和超出实现的定义；
所有调用仍与 Host Binding.AllowedModels 求交，原生历史继续校验同模型身份。
响应按各协议原合同解析；Kimi Chat 记录服务端别名，Kimi Responses 不填写
ResponseModel。两者保留请求型号，现有严格比较的协议继续拒绝不匹配响应，
不新增跨协议统一同名规则。
目录接纳与厂商实测分离，旧证据中的固定型号不得随新目录自动扩大或改写。

Gemini 请求/历史编码与 OpenAI 服务等级估价中的名称分支具有独立行为，删除会改变
既有请求或价格。它们不属于本次目录名称准入，本次保留；若未来改为数据驱动，必须
先定义能表达其语义的字段并验证迁移，不得仅删除分支。

本次先升级一次 SDK。之后同能力的新增可分发外部版本化 JSON，Host 加载后创建
新 Client；编译内置默认仍在构建时固定，更新内置默认必须重建分发。

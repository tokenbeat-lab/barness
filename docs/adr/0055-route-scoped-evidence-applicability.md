# 按路线判断证据适用性并退役固定续期控制器

Provider 验收中，完整源码与目录哈希被同时用于追溯、当前资格和新执行权限，导致补测试、修消费者或新增型号牵动无关路线。维护者已批准[精简方案](../../.scratch/provider-integration-audit-20261027/simplification-plan.md)，采用以下决定。

原测量绑定当时真实来源、二进制、输入、账户、原生捕获、授权与消费，保持不可变。当前适用性按实际产品差异和本路线实际使用的型号判断；消费者变化先离线重验，完整全库/全目录哈希不再作为所有路线同时失效的条件。缺少必要来源或原件时仅列明相关缺口；公共协议或生命周期确有共享影响时扩大相应范围，不自动发起付费。

每个阶段固定自己的实际来源与输入，通过原件引用连接；授权文书若不是普通测试的实际输入，不触发第二轮完整普通。当前执行统一已有的单次 grant/claim 与原生预算；删除固定 renewal/recovery 控制器、旧权限 fallback 和重复过程包装。旧授权、nonce、账本、失败、UNKNOWN、暂停状态与原件保留，历史只读核验使用固定旧版本。原 grant 期限按当时执行时刻验证，不能启动新的执行。

正式资格可以引用已完整覆盖正式合同的真实候选测量及当前离线适用性结论；原报告的 stage/mode/时间不改，缺少真实场景仍须补该路线。候选、受控和回放不能因一份声明变成真实测量。

Kimi 两站六路线的十项合同允许固定的两来源组合：同路线、型号、账户、地区、租户和 SDK 的原九项测量，加一份绑定原 manifest 的 `xai-origin-history` 单项测量。分别保留两次来源、授权、预算、时间、实际进程退出与完整原件，另留逐项覆盖和当前资格结论；不合成一次十项采集，也不修改原报告。消费者重建 Host 请求，经当前编码器比较捕获 wire，再解析真实响应。已审源码差异仅以具体 Provider/API/文件/前后 SHA 对适用，不产生未来变更豁免。新单项或旧九项均不能独立取得十项资格。

MiniMax 国际 Messages 的十四项合同另允许固定十三加一：完整保留原失败测量、原退出1及全部账本，只贡献除 thinking-on 外经核验的十三项；唯一未恢复失败必须是 thinking-on。合法的相邻初错/恢复仍按原合同验证。新单项只接受 Messages/M3/standard/candidate，绑定原 manifest，1调用/1HTTP、零重试、输入及输出各2048、120s/180s、USD0.01。单项 complete 始终 false；其成功不改写旧 FAIL。两包同账户、地区、租户、SDK及适用型号事实，当前编码和响应解释均须通过。原 formal 与新 candidate 的真实测量可以共同证明当前正式合同，不要求另买整组十四项。


MiniMax 国际 Messages/M3/standard 固定单项若实际 wire 无 `cache_control`，按已固定官方 M3 自动缓存文档将**独立缓存写费**判为 `NOT_APPLICABLE`。这不是缺失计数等于零：原始 creation 省略及 `UsagePartial` 保持；input/output/cacheRead 等实际计费计数仍须有效，显式 null、正写入、TTL、显式缓存控制或其他身份不适用。此限定修正取代固定补项“四计数无条件必报”的过宽消费者规则，不改变 SDK、产品 Usage、价格或 ADR-0041 的正写入缺价保护。依据见[离线研究](../../.scratch/provider-minimal-paid-supplement/minimax-failure-research.md)。

新采集若后验验证失败，必须先写最终 FAIL/audit，再对当前尚未完成的 attempt 生成最终 seal；最终封存后消费者只读。历史两份 FAIL/exit1 与 seal/report 差异保持，不给旧包重封存；当前语义回放与可供正式组合的完整证据分别判定。诊断性复原件不能冒充成功报告或真实退出0。原件完整性/退出合同仍不满足时列出最小缺口，不新增历史兼容控制器来凑通过。

只支持上述两个已出现的固定缺口，不引入通用场景图、嵌套组合或续期控制器。组合是只读证据引用，不签发执行权限；受控组合只能证明验证机制。MiniMax 的两包须同为 live 或同为 controlled，原失败与新成功分别核验真实 producer argv、二进制、来源与 selectedInputs、数字退出和传递库存。新资格逐项绑定各自测量，不伪造统一时间、授权或预算。旧失败采集器可能没有成功 bundle 库存；仅对该 FAIL/exit1 的 baseline，允许以已绑定 stderr 的唯一精确原生目录标记、同会话 claim、固定原生目录布局及完整封存包共同证明归属，不补写旧回执。新成功单项仍必须有完整 producer bundle 库存。新采集仍须独立付费批准；本次只授权离线实现和受控/普通验证。取得正式资格还须本型号正式目录事实一致。细节见 [Kimi 合同](../../ai/live/REGIONAL.md#kimi-原九项与单项补采)和[MiniMax 实施合同](../../.scratch/minimax-thinking-supplement/spec.md)。

本决定替代 ADR-0047/0050 的固定轮次与递归前序执行规则、ADR-0049 的无关消费者/目录变化强制重采规则，以及 ADR-0051/0053 中跨阶段来源/输入恒等与全局资格失效部分。它们的隔离、预算、不可复活权限、独立核验和留存约束继续有效。race/压力按实际影响选择；无并发/负载影响时可有依据地不适用，未获授权的适用阶段仍为 NOT_RUN。

不建立新调度服务、依赖图或历史兼容库。实现与验证见[唯一当前状态](../../.scratch/verification-simplification/status.md)。本次授权仅含普通 E2E、离线回放和受控进程；禁止付费 live、race、压力及恢复暂停轮次。

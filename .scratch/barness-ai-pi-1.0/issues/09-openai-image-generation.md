# 09: 通过 GenerateImages 完成 OpenAI 图像生成

**What to build:** 宿主通过 Client 或 HookedClient 的 GenerateImages 生成 OpenAI 图片，使用协议专属选项，取得完整且经过整体校验的图片集合、模态用量、估算成本和调用元数据。

**Blocked by:** 06 — 完成 TypeSafe 评分、是非与原生 JSON 输入；07 — 验证 unary 调用的故障与资源释放。

**Status:** resolved

**依据：** 规格“图像：共同契约”“图像：OpenAI Images”“用量、计价与观测”、实施设计第 7–9、11、13 节，以及 ADR-0002/0005/0007/0008/0009/0010/0014/0018。

- [x] 先扩展现有 fixture runner 的 generateImages 入口，写生成、多图、非法选项、错误协议或操作、未启用策略、缺图、坏图、拒绝和用量缺失场景，再实现图像调用。
- [x] Client 与 HookedClient 提供同步 GenerateImages，支持 context 取消，不产生 delta，不接受 SimpleOptions；nil 选项使用协议默认，ImageOptions 为封闭的协议选项集合，不引入通用选项袋。
- [x] 无参考图时经唯一共享 HTTP 客户端直连 OpenAI × openai-images × image 的生成端点，使用 Bearer 凭据；授权、凭据快照、绑定重试、尝试准入、响应回调与终态观测复用已验证 unary 生命周期，默认不重试。
- [x] 提供数量、尺寸、质量、背景、输出格式、输出压缩和审核级别的类型化选项，按型号能力校验；数量在 1–10 及有效输出上限内，提示 1–32000 字符，透明背景须配 png 或 webp，压缩仅允许 jpeg/webp 且在 0–100。不支持的选项在发请求前拒绝。
- [x] 图像子策略显式启用且各容量为正，限制输入与输出图片数量、单张输出和输出总字节，构造时深复制；未启用时以 invalid_request/scope 返回带元数据的失败，旧聊天配置继续有效。
- [x] 图像输入为提示与有序参考图，输出为独立封闭的有序文本/图片块；输出类型不改变既有聊天图像类型。参考图编辑和 mask 能力由 10 交付，本切片验证无参考图的完整生成路径。
- [x] 遍历全部返回图片，严格校验 base64、声明 MIME 与文件头，按响应格式、最终冻结请求格式及协议默认值的顺序确定格式；数量、单张字节和总字节都通过后才发布。任一图片无效时输出整体为空，用量及元数据保留。
- [x] 成功响应按总输出上限读取，不被聊天帧上限误杀；超大 JSON、坏 JSON、坏 base64、MIME 不符或完成但缺图均在 response 阶段失败且不重放，资源超限为 resource_limit，协议损坏为 protocol，厂商拒绝或阻断为 upstream_error。
- [x] 构造前和回调后检查已知输入与请求长度，base64 先估算尺寸，响应读取和图片校验避免多份响应体及 base64/解码内容长期同时常驻。任何路径均不读取任意文件或下载 URL。
- [x] 回调后重新核对授权型号、允许字段、生成端点语义与最终请求限额；请求不能加入 stream、partial images、响应格式、user、外部资源或续接状态。结果格式和计价依据最终冻结请求，扩大授权为 tenant_denied，无效回调为 callback_failed。
- [x] Usage 只增加可选模态分项，聊天序列化保持不变；保留文本/图片输入输出 token 的未报告与零差别。usage 缺失为 unreported，所需总量或输入/输出明细缺失为 partial，齐全才为 complete；先登记用量再校验图片。
- [x] 图像费率按已声明模态存在、非负且有限，每个乘积独立计算后相加，缺用量分项只按已知部分估价；直接 Images API 不设缓存输入费率，不叠加按张派生价。实际费率与型号能力由 11 重新核验并纳入目录。
- [x] x-request-id 记为厂商请求 ID，响应没有 ID 或型号时不填 ResponseID/ResponseModel；不保留 revised prompt。Observer 只含操作、尝试、用量等元数据，模态分项进入审计白名单，不含提示、base64 或错误正文。
- [x] P08 场景、P0 与追溯随交付登记；所有原生图像 fixture 明确跳过 pi 差分，账本登记为扩展路线，并用离线 E2E 断言登记成立。目录包含核验有显式原生图像豁免，不伪称差分通过。
- [x] 为 OpenAI 图像补齐协议 ADR 与 SDK 不能满足有界 JSON 编辑的直连理由，修订用量、资源、扩展与契约说明；完成聊天/分类回归、取消与释放检查，产出带版本、目录快照及脱敏审计的离线证据。真实冒烟前不宣称首批图像型号已支持。

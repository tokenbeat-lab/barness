# 07: 验证 unary 调用的故障与资源释放

**What to build:** 云端宿主能在分类调用被取消、超时、限流、拒绝准入或收到损坏响应时确定为什么失败、哪些尝试已经发生，以及资源是否释放。该工单用首条 unary 路线证明可供图像复用的完整生命周期。

**Blocked by:** 05 — 通过 Classify 完成 TypeSafe 单选调用。

**Status:** resolved

**依据：** 规格“重试、准入与资源”及测试组“生命周期”“资源”“回调与观测”、实施设计第 7.5–7.6、8 节，以及 ADR-0003/0006/0007/0008/0009。

- [x] 先用既有假时钟、Provider 替身和资源探针写出失败方式，再修复发现的缺口；断言公共结果、实际请求、尝试、观测和探针读数，不断言内部调用顺序。
- [x] 覆盖调用开始前、配置解析、准入等待、退避、读取响应体期间的取消和总截止时间，以及连接、响应头、读空闲超时；终态与错误阶段正确，各调用只影响自身资源。
- [x] 覆盖 401/403、422、429、529、连接失败和绑定重试耗尽；默认零次重试，显式重试固定同一绑定、凭据、目标和目录快照。每次实际网络尝试有唯一 AttemptID 与独立准入许可，准入拒绝不伪造已发送尝试。
- [x] 请求头与请求体回调每逻辑调用各执行一次，重试复用最终冻结请求；成功响应的响应回调只执行一次且只接收元数据。回调失败、context 结束和无效回调均正确保留错误可识别性。
- [x] 200 后读断、坏 JSON、缺答、无效单选分布、资源超限、回调失败和取消均不重发成功请求；失败不会因 HTTP 状态或 SDK 默认规则变成隐藏重试。
- [x] 成功 JSON 大于 MaxFrameBytes 但小于 MaxOutputBytes 时能读完，恰在上限的响应可成功，超过总量时在读取中失败；非 2xx 错误体仍遵守独立上限且超限不重试。
- [x] 验证响应体关闭和许可释放涵盖所有失败路径，许可保持到响应读取与解析结束；探针无活动调用、响应体、准入许可或等待者泄漏，并验证后续调用仍能获得许可。
- [x] 构造后改变原分类子策略不改变限额；nil 子策略、非正容量、超限状态或问题、回调插入超限问题分别被拒绝，检查发生在不必要复制或网络发送之前。
- [x] 未解析调用只带可信 scope 与入口操作；已解析调用、AttemptStarted/Finished 和 CallFinished 归属一致，使用同一用量完整性轴；Observer 慢、拥塞、错误或 panic 不改变调用结果，记录无正文或秘密。
- [x] PhaseResponse 进入公共错误契约，errors.Is/As 的既有匹配规则保持成立；完善对应 ADR 与追溯，交付可重放的离线 E2E、race、资源释放和脱敏审计证据。

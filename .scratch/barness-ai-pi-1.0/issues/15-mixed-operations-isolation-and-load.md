# 15: 验证三种操作共用 Client 的隔离与设计负载

**What to build:** 本地程序与云端宿主可在同一个只读 Client 中并发调用聊天、图像和分类，并获得明确的身份、用量、资源边界与运行依据。宿主示例带可重复压力证明的有限策略，展示每条新路线可独立停用。

**Blocked by:** 13 — 完成 Google 参考图编辑与请求守卫。

**Status:** ready-for-agent

**依据：** 规格测试组“身份与授权”“生命周期”“资源”“回调与观测”及“升级与回退”、实施设计第 6.6、7.6、8.3/8.6、13 节，以及 ADR-0001/0002/0003/0008/0009/0017。

- [ ] 先列混合操作并发下的串租户、串绑定、串凭据、快照竞争、过早释放许可、输入复制膨胀、输出半发布、策略修改泄漏及观测泄漏场景，再修复或补齐宿主示例。
- [ ] 一个 Client 并发混合 chat、image、classifier；跨租户同名 Binding、共享账户凭据引用的不同操作 Binding、同型号 ID 跨操作并存均按四维身份授权，请求、结果与所有观测归属正确。
- [ ] 旧零值 Binding 只允许聊天；分别用图像和分类入口误用聊天 Binding、用聊天入口误用新操作、使用未知操作或错误协议选项，证明拒绝发生在凭据读取和 Provider 请求之前。
- [ ] 凭据撤销或轮换竞争遵守一致快照：前置不一致不自动重解析，已解析调用及其重试固定原快照，新调用使用新快照；不跨 key、账户、端点、操作或 Provider 回退。
- [ ] 验证各操作取消、超时、失败和重试不会释放其他调用许可或污染其结果；混合准入满足租户与进程上限、等待者和等待时限，响应读完及解析结束前许可不释放。
- [ ] 验证构造后修改原目录、图像/分类子策略、请求或选项不改变 Client 的有效快照和在途请求；调用边界的新增可变结构有独立复制。
- [ ] 本地与云端示例通过公共入口展示显式有限图像/分类子策略、独立 Binding、合法共享凭据引用、类型化结果、取消和错误处理；业务置信阈值、转人工和路由仍由宿主负责。
- [ ] 示例注释明确设计负载、并发、请求/参考图/mask 大小、输出图片大小及数量和内存预算，先据实测选择数值；不把聊天容量直接当作图像通用默认值。
- [ ] 在设计负载下验证图像 base64 膨胀、JSON 整体读取、输出整体校验与并发峰值，记录可达堆增长、Provider 替身副本影响、吞吐、每项限额占比和 headroom；沿用 ADR-0017 的 75% 余量判据与明确的内存预算，不依赖精确机器耗时。
- [ ] 压力运行仅由现有显式开关或发布门禁启用，未运行记 NOT_RUN；有界捕获或记录生成参数，避免证据副本主导被测内存。大于帧上限的合法 JSON 能成功，单图、总图、总响应或请求超限及时失败，失败输出为空且无资源泄漏。
- [ ] Observer 混合记录只含批准的操作、身份、版本、尝试和用量元数据，不含提示、base64、分类状态、答案或错误正文；拥塞、慢消费者、错误与 panic 不改变模型调用结果，丢弃/失败可由既有观测统计识别。
- [ ] 分别禁用 TypeSafe、OpenAI 图像和 Google 图像 Binding，验证新调用被拒、其他操作仍能运行、已发请求不被承诺撤销，尝试消耗保留；不引入兼容 shim 或双写路径。
- [ ] 修订示例说明、资源/隔离 ADR 和 T/C/H 需求追溯；交付宿主 E2E、混合操作 race、资源探针、设计负载压力报告及脱敏审计证据。

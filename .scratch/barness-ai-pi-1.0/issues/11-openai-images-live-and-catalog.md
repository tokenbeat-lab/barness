- [x] 先列冒烟误判、预算与矩阵合并失败方式，再扩展 P08 场景；真实调用均经公共 Client，复用独立进程、双开关、本组合低权限凭据、固定真实目标和账户/区域别名。

- [x] 首批固定 gpt-image-2.5-sunburst-2026-09-08；实施时重新核对官方日期快照、输入保真度、尺寸、质量、mask 与输出格式能力，保存官方来源和抓取日期，能力以本组合实测为准。

- [x] 检查图片可读、格式、尺寸、数量约束和协议结果，保留可验证的图片校验产物，不作像素相等断言；请求/响应捕获有上限且凭据脱敏，Observer 不含提示或图片。
- [x] 官方费率按文本/图片输入输出分别录入，保留来源与抓取日期；直接 Images API 不录缓存输入费率、不重复加按张派生价。确认缺 usage 与缺明细的上报状态和已知部分计价。

- [x] 未运行或缺凭据为 NOT_RUN，厂商拒绝 JSON 编辑为 FAIL 并记录阻塞；编辑是必交能力，不能以 UNSUPPORTED 或移除编辑场景通过门禁。mask 等可选能力允许按型号及证据明确标为不支持。

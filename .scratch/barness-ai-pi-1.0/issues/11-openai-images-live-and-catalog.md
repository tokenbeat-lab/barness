# 11: 完成 OpenAI JSON 编辑真实冒烟

**What to build:** 维护者能凭 OpenAI 本组合的真实 API 证据确认 JSON 编辑确实被接受，再声明首批图像型号的生成、编辑和可选能力支持范围，采用可追溯的费率及目录快照。

**Blocked by:** 10 — 完成 OpenAI 内联 JSON 编辑与 mask。

**Status:** claimed

**依据：** 规格“图像：OpenAI Images”“支持矩阵”“发布门禁”、实施设计第 9.4–9.5、11、16 节，以及 ADR-0016/0017/0018。

- [ ] 先列冒烟误判、预算与矩阵合并失败方式，再扩展 P08 场景；真实调用均经公共 Client，复用独立进程、双开关、本组合低权限凭据、固定真实目标和账户/区域别名。
- [ ] 首个真实检查为内联 JSON 编辑；通过后执行一张生成和型号支持时一张 mask 编辑。记录完整路径、响应状态、请求 ID、输出格式、用量形状与已发请求的消耗，不改用 multipart 或其他协议掩盖失败。
- [ ] 首批固定 gpt-image-2.5-sunburst-2026-09-08；实施时重新核对官方日期快照、输入保真度、尺寸、质量、mask 与输出格式能力，保存官方来源和抓取日期，能力以本组合实测为准。
- [ ] 图像预算独立按调用、图片张数与分辨率控制，首期每组合不超过 4 张、最大冒烟分辨率为 1K/1024×1024；任何环境重试计入预算，耗尽为 FAIL。
- [ ] 检查图片可读、格式、尺寸、数量约束和协议结果，保留可验证的图片校验产物，不作像素相等断言；请求/响应捕获有上限且凭据脱敏，Observer 不含提示或图片。
- [ ] 官方费率按文本/图片输入输出分别录入，保留来源与抓取日期；直接 Images API 不录缓存输入费率、不重复加按张派生价。确认缺 usage 与缺明细的上报状态和已知部分计价。
- [ ] 支持矩阵的 P08 行明确为 image/OpenAI/openai-images，仅用本组合报告合并；验明操作、Provider、协议及全部预期能力，报告不完整或不匹配不能置完整通过状态。
- [ ] 未运行或缺凭据为 NOT_RUN，厂商拒绝 JSON 编辑为 FAIL 并记录阻塞；编辑是必交能力，不能以 UNSUPPORTED 或移除编辑场景通过门禁。mask 等可选能力允许按型号及证据明确标为不支持。
- [ ] 编辑真实通过之前不纳入支持声明；通过后纳入固定快照型号及已确认能力，升目录版本并重建价格与目录快照，更新对应 ADR、契约与追溯。
- [ ] 交付本组合真实报告、带来源 fixture、脱敏审计零发现、支持矩阵原子合并及离线回归证据；与 TypeSafe 冒烟装置共享的格式变更沿用其既有一致性要求，不新增第二套矩阵。

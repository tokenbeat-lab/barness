# 01: 拆分目录职责，保持现有聊天行为

**What to build:** 为后续三种模型操作整理现有目录的职责边界，使宿主继续使用完全相同的聊天型号、查询、目录快照与调用行为。该工单只做有现有行为证明的预重构。

**Blocked by:** None (can start immediately).

**Status:** resolved

**依据：** 规格“模型操作与目录”、实施设计第 6.2 节，以及 ADR-0010、ADR-0018。

- [x] 按型号定义、内建数据、查询与目录快照职责整理现有实现；每个文件不超过 500 行，不引入兼容层、平行目录或推测性抽象。
- [x] 现有 Model 字段及 keyed struct literal 的可用性、Catalog 的公开字段与聊天查询含义保持不变。
- [x] 内建型号、价格、目录版本、JSON 形状与内容哈希保持不变；目录深复制和配置只读语义继续成立。
- [x] 先列出可能的行为回归：型号遗漏、查询错配、价格或哈希漂移、构造后配置修改泄漏。用现有公共入口 E2E 与目录包含验证覆盖它们，不新增实现细节单元测试。
- [x] 运行现有离线 E2E、受影响的冻结基线差分与 vet，产生带版本、目录哈希和脱敏审计结论的可重复证据包；差分无新增待处理项。

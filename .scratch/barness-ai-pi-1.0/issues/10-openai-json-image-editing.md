# 10: 完成 OpenAI 内联 JSON 编辑与 mask

**What to build:** 宿主在同一个 GenerateImages 入口提供有序参考图进行 OpenAI 编辑，可使用型号允许的 mask 和输入保真度；请求及可信回调都受内联图片、型号能力与资源限额约束。

**Blocked by:** 09 — 通过 GenerateImages 完成 OpenAI 图像生成。

**Status:** resolved

**依据：** 规格“图像：OpenAI Images”“图像回调边界”、实施设计第 8.1、11、13 节。

- [x] 先写生成/编辑端点选择、JSON 参考图和 mask、图片数量与大小、file_id/远程 URL、mask 尺寸、保真度、回调越权及最终格式的成功与失败 fixture，再扩展编辑实现。
- [x] 无参考图使用生成端点，有参考图使用编辑端点；编辑请求为 JSON，只含内联 data URL 图片和 mask。回调不能改变已选端点或操作，生成不能被改写成编辑，编辑不能移除必需参考图。
- [x] 参考图复用现有 Image 类型，有序、独立复制，MIME 合法且 base64 严格校验；不接受文件路径、file_id、远程 URL 或其他厂商资源引用，不自动读取或下载资源。
- [x] 构造时与回调后均限制每个内联 URL 不超过 20971520 字符、GPT image 参考图不超过 16 张，并取宿主策略、协议和型号限制的较小值；先用已知长度及 base64 尺寸估算检查，再复制或解码。
- [x] mask 要求参考图存在、与第一张参考图同尺寸且型号支持；mask 计入宿主输入图片数量及单图字节限额。失败发生在网络发送前，包含回调追加 mask 或大图的情况。
- [x] 输入保真度按型号能力验证，例如 gpt-image-2 必须省略；首批 2.5 型号的允许值由 11 的真实证据确定。尺寸、质量、透明背景、格式与压缩等组合也按最终请求验证，不因生成路径已经通过而跳过编辑检查。
- [x] 支持任意尺寸的型号遵守其尺寸硬约束：边长为 16 的倍数、宽高比 1:3–3:1 和最大尺寸规则；相关规则来自带来源的型号能力，不在 adapter 以型号名分支猜测。
- [x] 请求回调可在允许范围内修改输出格式等选项，输出 MIME 与文件头按最终请求及真实响应校验；回调加入 file_id、远程引用、stream、未知字段、改变型号或突破限额时得到对应 callback_failed、tenant_denied 或 resource_limit。
- [x] 编辑复用生成路径的全部图片映射、整体发布、模态用量和失败不重放规则；验证响应回调次数、厂商请求 ID、响应体关闭与许可释放。
- [x] 修订图像协议 ADR、契约、扩展说明和 P08 追溯；交付生成/编辑回归及经脱敏审计的可重放离线证据。JSON 编辑真实接受性仍由 11 证明，运行时不添加 multipart 回退。

# 16: 独立评估中文分类效果

**What to build:** 业务负责人可用固定中文标注集、固定 Jev 版本和可重复流程评估分类效果，查看准确率、误判与置信校准，而不把协议兼容通过当作业务准确率证明。

**Blocked by:** 08 — 完成 TypeSafe 真实冒烟与目录纳入。

**Status:** resolved

**依据：** 规格 User Story 87、“可重复产物”与分类运维事实，实施设计第 10.7 节。

- [x] 固定一个版本化、可复用的中文标注集，采用合成或获准使用且脱敏的数据；记录标签定义、标注依据、样本数量、标签分布、任务范围及数据集内容哈希，避免凭一次演示臆造业务标签真值。
- [x] 评估经宿主使用公共 Classify 入口，固定 jev-1.13.0、问题定义、目录/价格版本与实际响应型号；不在库中新增置信阈值、业务路由、转人工或模型微调能力。
- [x] 先用现有受控 Provider E2E 验证评估流程的失败方式：数据集缺标签、错问题键、模型/数据集版本漂移、缺答、协议失败、用量未完整上报、预算耗尽、取消及报告不完整；随后实现或补齐报告流程，不新增测试接缝。
- [x] 真实业务评估有独立的显式启用、凭据隔离、问题/调用/重试预算及取消控制，不消耗或伪造支持矩阵冒烟结果；费用按实际尝试记录，已发请求的用量保留。
- [x] 报告至少包含准确率、按标签的误判分布与置信校准统计，并展示可追溯的错误样本；适用范围、样本量、任务与版本完整记录，不用未约定的准确率阈值冒充规格要求。
- [x] 不把缺答、失败调用或未执行样本丢弃后只报告成功样本的分数；样本状态、失败数量与指标分母明确，未运行报告 NOT_RUN，缺少真实结果不能写为已完成效果评估。
- [x] 区分确定协议 fixture 的流程验证和真实型号的业务效果结果；固定数据集与流程可重复执行，报告记录运行时间及模型响应的不确定性，不要求真实生成答案逐次完全相同。
- [x] 结果产物含数据集与配置哈希、型号版本、指标、错误分析、预算/用量和脱敏审计结论；Observer 不含数据集状态或答案，允许的评估内容只进入获准的评估证据。
- [x] 文档说明如何重放和解释结果，把业务效果追溯到独立评估证据；实际评估通过完整性与审计检查后完成本工单，不以协议冒烟 PASS 代替结果。

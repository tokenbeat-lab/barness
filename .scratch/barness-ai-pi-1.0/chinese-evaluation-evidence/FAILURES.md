# 中文分类评估失败方式（实现前）

既有接缝：受控 Provider → 公共 Client.Classify → 宿主评估产物；不增加库内探针或模拟分类器接口。

- 缺真值、未知标签、重复样本、无标注依据或分布缺失：加载拒绝，零请求。
- 数据集版本/内容哈希、问题键、固定模型、目录版本/哈希漂移：加载拒绝；响应型号漂移保留尝试并 FAIL。
- 缺答、错问题键、非法分布、HTTP/协议失败：样本失败，明确上报用量保留，全部样本仍在指标分母。
- usage 缺项/未报：不能当免费或完成；保留可用答案供诊断，标为 usage_incomplete。
- 调用、问题、尝试/重试预算不足：停止新调用，剩余样本 budget_exhausted，不过滤样本。
- 取消：停止新调用；已发送尝试、用量和取消样本保留，其余 cancelled。
- 未启用/无凭据：NOT_RUN，全部样本 not_run，分数为 null。
- 报告删样本、改指标、改版本、改预算计数或无审计结论：完整性核验拒绝。
- Observer 混入正文/答案、任何证据漏凭据：既有 auditbundle 拒绝，不出验收通过。

固定 fixture 只证明上述流程；真实评估必须独立开关、隔离进程、实际型号和自己的审计证据。

# 工单 07：先验失败方式与公共验收边界

基点：4f90386fa4c879dddfa3013cce778c44de873acc。接缝由工单明确授权：
Client/HookedClient.Classify、受控 HTTP Provider、宿主解析/准入/Observer、假时钟与资源探针。
下面在生产代码修改前记录失败方式；每个修复先经对应离线 E2E 复现。

| 失败方式 | 宿主可见契约 |
| --- | --- |
| 开始前已取消/到期 | scope 分类，无解析、复制或 HTTP，无 Attempt，仅可信归属 |
| 绑定或凭据解析时取消/到期（包括解析器成功返回时 context 已结束） | binding/credential 阶段，无 HTTP，未解析归属 |
| 内置或注入准入等待取消/到期、准入拒绝、重试被拒 | admission 阶段，仅记录真正发出的 Attempt，释放等待者和许可 |
| 退避取消/到期 | request 阶段、aborted，保留此前失败 Attempt，退避中无许可 |
| 连接、响应头、读空闲超时 | deadline_exceeded，尝试时限 error；200 后不重放 |
| 200 后取消/总截止时间、读断、坏 JSON、缺答或坏分布 | response 阶段，整体答案为空、明确用量保留，无重放 |
| 401/403/422/429/529/连接失败，零重试或显式耗尽 | 初始请求分类、独立 AttemptID/许可、同一冻结快照 |
| 回调错误、无效返回、context 结束、panic | 错误链可 Is/As；错误文本固定；资源释放；请求回调各一次，成功响应回调一次 |
| JSON 大于帧上限、恰好输出上限、超过上限；非 2xx 恰好或超错误体上限 | 独立字节预算；超限只探测一个额外字节、读取中结束；不重试 |
| 子策略 nil、零/负容量、源策略构造后变化、状态/问题/回调超限 | 在不必要复制、准入或网络前拒绝，Client 持有独立配置 |
| Observer 慢、拥塞、返回错误或 panic | 不影响结果；有界且可计数；归属、用量完整性一致，无正文或秘密 |
| 任一调用失败或并发取消 | body、call、permit、waiter 无泄漏；其他调用继续；后续请求可获许可 |

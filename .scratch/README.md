# Scratch 导航

本页只索引本地工作目录。规范、工单标签、历史验收和当前资格各有自己的来源；此处不复制阶段结果、轮次、预算或授权。没有集中状态的目录明确标注，以工单追加记录追溯，不把旧报告提升为新的状态源。

当前操作统一查[测试 SOP](../docs/agents/verification.md)、[工具合同](../tools/verification/README.md)和[工具迁移映射](scratch-artifact-remediation/tool-migration.md)。表中脚本链接用于识别归属，不构成执行指令；地区操作边界只查其唯一状态及工具入口。研究、展示和审查目录按实际用途登记，不强行补 spec。

“无已确认直接依赖”指未发现普通 Go 测试直接读取该目录文件，不代表可以删除；显式 Python 合成进程测试另行标注。仅作为追溯链接与实际读取输入分别处理。[留存输入](../ai/e2e/testdata/retained/README.md)记录已迁出 scratch 的普通夹具；[输入清单](scratch-artifact-remediation/input-dependencies.json)保留原盘点范围。

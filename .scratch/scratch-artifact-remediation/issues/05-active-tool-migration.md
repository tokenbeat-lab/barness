## 先列失败方式

1. 新run/consume/cleanup入口不可执行或测试无法定位根目录；Jev新Python路径不存在、旧路径仍被活动调用。
2. 采集器遗漏新工具/测试或Jev非Go源码；Go独立选择器与采集器不同；新增、删除、改动及忽略源码不能拒绝旧快照。
3. 无Key普通入口继承live/race/压力/持久Go配置，启动隐式重负载；只读消费者启动验证。
4. 输出/真实退出/原生资格被父进程伪造，最终写入或采集失败后留PASS；超时、取消或脱离进程组的管道无限等待。
5. 清理越界、漏传递依赖、错误plan哈希、观察期不足、恢复覆盖；只在临时合成repo验证，不操作真实证据。
6. 原历史脚本/README/pin丢失或被改写；旧Jev来源map被刷新以迁就新路径；recovery7被恢复。

# 工单 10 公共进程接缝

现有 spec R20 已选择公共 CLI/进程接缝。逐片测试固定轮次操作入口，不访问真实服务或凭据。

失败方式：未知路线/阶段、未提交源码、源码集合新增/删除/修改、二进制或计划漂移、缺少双轴审查或明确本轮人类预算、旧授权/旧轮次/布尔数字、复制工作树重新 claim、并发超额美元预留、预先存在输出、失败/取消用量未知后释放余额、依赖失败后继续、环境串入其他 Key/proxy、未建立预发送美元上限、错误或缺少自身报告、23 行输入缺项/重复/错身份、GLM 原件与 canonical launcher pins 不一致、关闭轮次回退、public importer 失败后发布矩阵。

开发验证只运行定向普通离线进程测试。真实调用和 race 由父任务按仓库验证策略另行记录。

# 06 before-code failure modes — confirmed public seam T01

Recorded before production code or tests. Scope: basic Messages text, independent from Chat/Responses; real raw origins are `protocol-exploration/messages/02-basic-sdk-query`.

1. Wrong Provider/API/model/Binding or auth/path/query creates cross-account attribution or sends to the wrong service.
2. Native Anthropic defaults append cache/TTL, browser access, beta, display, eager streaming, adaptive, block binding or managed effort without GLM evidence.
3. Simple omitted reasoning generates disabled thinking for GLM-5.3. Explicit unverified controls are silently weakened or forwarded.
4. A trusted callback restores unsupported advanced fields or beta headers after normal construction. Reject before any Attempt.
5. Model or simple SamplingParams / per-level maps leak into Messages, changing its documented ignore contract.
6. Initial zero usage masks final actual input/output; absent cache creation or reasoning fields becomes fabricated reporting completeness.
7. X-Request-Id is lost from Attempt/error metadata because native Anthropic reads Request-Id.
8. Missing message_stop, missing stop reason or stream error appears successful. One terminal failure must preserve available content and attribution.
9. A fixture is derived from another protocol or a synthetic wire guess, or a basic replay is reported as full Messages/live acceptance. Preserve raw SSE hashes and honest scope.

Vertical slices: actual text + header/default request; explicit options and callback guard; terminal failures and usage. Existing native Anthropic E2E and frozen differential are regression gates. No new paid calls are needed: authorized exploration has separately audited immutable bundles.

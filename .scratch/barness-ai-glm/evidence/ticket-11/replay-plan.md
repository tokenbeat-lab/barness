It does not modify or relabel original live evidence.

Public executable seam: explicit `^TestGLMCaptureReplay$`, build tag live, selected route plus one pinned archive. Mode=`replay`, kind=`glm-capture-replay-only`, separate report filename. Normalize only exact Host-generated paths: message.timestamp, message.durationMs, metadata.requestId, metadata.attempts[*].attemptId; Observer time/duration and its same local request/attempt paths. All upstream request/response/tool/item IDs, raw reasoning signatures, arguments, tool result pairing, usage fields, costs and native data remain exact. There is no generic ID exclusion.

Cancellation uses the captured partial bytes. This reproduces the observed cancellation boundary without inventing frames or erasing content differences. Event artifacts retain their fresh observation snapshots; immutable raw bytes and final Result are the deterministic comparison, since PartialView is an asynchronously observed live view rather than an event-time snapshot.

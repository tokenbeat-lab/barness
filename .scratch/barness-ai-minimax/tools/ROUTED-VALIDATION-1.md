# Routed validation 1: failure inventory before implementation

The agreed seam is the public auxiliary launcher CLI and its actual child
process boundary. Synthetic temporary Git repositories and subprocesses exercise
it without credentials or vendor traffic. The existing public Client E2E seam
covers native transport behavior; no private helpers become testing interfaces.

Preparation must refuse unknown or altered prior consumption and uncommitted
source. Its two fixed phases contain exactly GLM3 and legacy15; phase selection
cannot invent jobs or narrow the complete scenario selectors. China GLM and
DeepSeek must stay direct even with ambient proxies. Every international route
must use only the explicit credential-free loopback HTTP proxy. Proxy or endpoint
changes, missing independent source review, missing request authorization,
changed source/binaries/plan/checks or stale output must refuse before opening
the selected credential or reserving an intent.

Canonical one-shot intents must survive new output directories and worktrees.
Concurrent launches cannot both acquire credentials. An interrupted, missing or
edited report consumes its full original component allowance, rather than reset
the budget or become NOT_RUN. Native report shape and actual status remain
unchanged, including FAIL. Previous300 calls/300 Attempts and original GLM
history stay immutable. GLM capture publication requires three successful own
same-source reports and the new canonical four-file capture pins; old-round
receipts or failed/mixed captures cannot substitute.

GLM publication changes selected JSON inputs. Legacy preparation therefore uses
a new source freeze after raw selectors and views are committed, while both
phases share the same immutable round, canonical intent namespace and374/398
maximum. There is no automatic next round or process replay. These numbers are
an execution ceiling derived from the user's request, not a claim of an explicit
numeric reply.

## Operator boundary

Use `routed_validation.py prepare <out> --phase glm` for three complete GLM
processes. `check <out>` runs both vet modes, all no-key live tests and the
CONNECT-only visual proxy E2E. `preview <out> routed-validation-1-glm-chat`
shows the fixed job without acquiring a key. Only `run-selected` can read its
one selected `.env` name, after review and request receipts pass.

The independent reviewer fills `prerelease-source-review.json` from its template
with `decision: APPROVED`, a reviewer identity, exact canonical `authorizedRoutes`
and credential scopes such as `GLM_KEY: routed-validation-1/china-direct`.
For international providers the scope is
`routed-validation-1/international-loopback-proxy`. The parent writes
`execution-authorization.json` from its template with `decision: APPROVED`,
`authority: explicit-user-request`, the actual request reference and the SHA256
of the completed source review. Its request text, finite budget, accounting
scope, current source/binaries/plan/checks pins must match independently
recomputed values. Neither tool creates an APPROVED receipt or claims the user
gave a numeric reply.

Run each reviewed canonical name exactly once. Native evidence paths and
`<baseName>-command.json`/logs stay unchanged; only the global authority marker
is `routed-validation-1-<baseName>`. `summarize <out>` reports all eighteen
canonical intents, original300/300, current actual and conservative consumption,
and the674/698 current-renewal ceiling. Earlier standalone GLM-task history is
separate and unchanged. Missing/interrupted/changed reports reserve the original
component maximum. No key, output root, worktree or failure can reset an intent.

Settlement reopens the original native command and report on every summary,
including the other phase. Pinned source/binary manifests, plan, independent
review, request authorization and checks establish their provenance without
requiring that historical phase's HEAD to remain current. A plan-pinned relative
collection location and hash of the original checkout root prevent redirecting
the canonical intent to a copied proof. Reads remain inside the current owned
checkout, use directory file descriptors, reject every symlink component and
bound metadata, report bytes and bundle enumeration. An unavailable foreign
worktree is UNKNOWN and retains its full component cap. Stored budget numbers
alone never settle historical consumption.

Only if GLM3 own same-source reports all pass, invoke the existing keyless
`renewal.py glm-archive <new-out> --round routed-validation-1` with all three
native bundle paths, commit raw selectors/known usage, derive `glm-views`, and
commit views. A failed GLM process cannot publish new selectors. Then prepare
`--phase legacy` at a new source freeze for the fixed fifteen legacy processes;
both DeepSeek identities are included. A new source freeze does not change the
round or canonical one-shot namespace. No MiniMax or absent M Plan process is
in either paid phase.

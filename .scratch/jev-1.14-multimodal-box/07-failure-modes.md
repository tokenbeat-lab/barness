# Ticket 07 failure inventory (before implementation)

Baseline: `6c51ee83a270017ad0f1bcd54fb6dc9f98935b8d`; dependency 05 resolved.
Agreed seams: public `Client.Classify` and `HookedClient.Classify`, with the
existing controlled HTTP Provider, recorder, image fixtures and audited bundles.

- Projection: Choice single candidate/root/nested examples; Bool true and false;
  every ordered Score level; escaped question/criterion/object keys and arrays;
  untouched nulls, strings, numeric spellings and unrelated questions. A source
  shared with State/Instructions/context must upload once without changing scope.
- Scope: missing/null containers, type/identity fields, nonexistent/non-null
  slots, duplicate targets, invalid escapes/array indices, unused sources;
  unreferenced Score/Bool null roots invalid, unreferenced Choice null valid.
- Capability: Criteria only on explicit Jev 1.14 candidate; absent location,
  text formats for ordinary containers, image roots independent of text format;
  Decisions rejects all local criteria before credentials. Policy, binding,
  experiment, MIME and file constraints remain effective.
- Capacity: source count/decoded bytes, actual occurrences/expanded bytes,
  complete canonical Question including generated escaped keys, State and final
  native body; Hook expansion repeats all checks, including RawMessage values.
- Final freeze: legal Hook renames/retypes/reorders/changes levels and images,
  text-origin additions/removals, final MIME/hash/order independent of entry
  indices; disallow substring, identity/object keys, unknown resources, unused
  assets, unauthorized locations and authority/experiment changes.
- Legend: validate native echo against final frozen Criteria first, then replace
  only whole image values with null plus value references relative to Legend.
  Deterministic final asset indices; repeated occurrences, root/nested/escaped
  pointers and wide JSON; optional/no-image legends retain current behavior.
- Corruption: missing/extra/wrong/duplicate levels, reordered/changed image or
  text, stale pre-Hook rubric, invalid probabilities, legend without distribution;
  any bad answer clears all Answers/ImageInputs, retains unique legal usage and
  ResponseModel, one 2xx Attempt without retry. Private keys/bytes never reach
  public answers or shared Attempt/Observer records; hashes remain result-only.
- Runtime/regression: request/options/native snapshot ownership, frozen retry
  bytes, cancel and tenant/Actor denial, resource release; existing no-image
  legend, single Choice, wide JSON, bounded Jev rounding, Decisions scores and
  refusals. Box and formal catalog/support remain outside this ticket.

Each slice first runs a failing public E2E, then changes implementation. Final
full/race manifests include fixture hashes, input/config, final requests and
responses, result/error, Attempt/Observer, assertions, resource gauges and audit.
Real-service protocol and visual quality are NOT_RUN.
